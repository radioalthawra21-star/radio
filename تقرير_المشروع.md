# تقرير المشروع: نظام إدارة المهام | راديو الثورة

**Full-stack HRMS بالعربية** مخصص لإذاعة **راديو الثورة**.
المشروع قيد التشغيل فعلياً على **http://localhost:5173/** (Frontend) و **http://localhost:3000/** (Backend).

---

## 🖥 هيكل التقنية (Tech Stack)

| الطبقة | التقنية |
|--------|---------|
| **Frontend** | React 18 + Vite 5 + Tailwind CSS 3 + RTL |
| **Backend** | Node.js + Express 4 + Mongoose 8 |
| **قاعدة بيانات** | MongoDB Atlas (`radio.j0lovmb.mongodb.net`) + Local |
| **Auth** | JWT + bcryptjs |
| **AI** | DeepSeek / Ollama / Gemini (متعدد المزودين) |
| **PDF** | jsPDF + jsPDF-AutoTable |
| **UI Libs** | Lucide React, React Icons, Chart.js, react-chartjs-2 |
| **Container** | Docker & Docker Compose (3 services) |
| **Deploy** | Netlify (Frontend) + Render (Backend) |

## 🔄 سير العمل (Workflows)

### 📋 سير عمل المهام (Task Workflow)

```
pending → in_progress → completed → approved → final_approved
```

| الحالة | المعنى |
|--------|--------|
| `pending` |بانتظار التعيين |
| `in_progress` | قيد التنفيذ |
| `completed` | مكتمل (بانتظار التقييم) |
| `approved` | تمت الموافقة من المدير |
| `final_approved` | موافقة نهائية من الأدمن |

**مستويات الصعوبة:**
| المستوى | النسبة | الرمز |
|---------|--------|-------|
| سهل (easy) | 20% | 🟢 |
| متوسط (medium) | 50% | 🟡 |
| صعب (hard) | 100% | 🔴 |

### أنابيب التحرير (Editorial Pipelines)

نظامان مستقلان لتحرير النصوص الإخبارية بالذكاء الاصطناعي:

**1. أنبوب النص القياسي (Standard Editorial Pipeline)**
- 6 مراحل تحرير للنصوص الإخبارية
- واجهة: `/news/editorial-pipeline`
- API: `/api/editorial-pipeline`

**2. أنبوب الفيديوغراف (Couplet Pipeline)**
- 6 مراحل تحرير لإنشاء نصوص الفيديوغراف (مقاطع فيديو)
- واجهة: `/news/couplet-pipeline`
- API: `/api/couplet-pipeline`

**المراحل الـ 6 (مشتركة):**

### ⚙️ حاسبة التعويضات (compensationService.js)

محرك مالي متكامل:
- **حساب السعر اليومي:** monthlySalary / 22 يوم
- **حساب السعر الساعي:** monthlySalary / 176 ساعة
- **مضاعف الأوفرتايم:** 1.5x أيام العمل, 2.0x عطلات نهاية الأسبوع
- **أنواع الاحتساب:**
  - إجازة مدفوعة (annual, sick, maternity, emergency...) → 0 أثر مالي
  - إجازة غير مدفوعة → خصم (dailyRate × days)
  - إجازة ساعية → تلقائياً من رصيد الإجازة السنوية ثم خصم ما تبقى
  - مهمة (داخلية 100 ريال / خارجية 200 ريال)
  - أوفرتايم → hourlyRate × multiplier × hours
- **كشف التداخل المالي:** يمنع دفع أكثر من تعويض على نفس الفترة
- **Idempotency:** يضمن عدم تكرار بنود الراتب عند إعادة المعالجة
