═══════════════════════════════════════════
تيار العمل الكامل (Complete Flow):
═══════════════════════════════════════════

الموظف يضغط "تسجيل حضور"
  → Attendance.jsx → checkIn() → attendanceService.js
  → API: POST /api/attendance/check-in → authMiddleware.protect()
  → attendanceController.checkIn()
  → Attendance.findOne(اليوم) ← يمنع الحضور المزدوج
  → attendance.checkInEmployee(time) ← يحسب التأخير عن 9:00 صباحاً
  → يحفظ في MongoDB → رد: "تم تسجيل الحضور بنجاح"

الموظف يضغط "تسجيل انصراف"
  → Attendance.jsx → checkOut() → attendanceService.js
  → API: POST /api/attendance/check-out → authMiddleware.protect()
  → attendanceController.checkOut()
  → Attendance.findOne(اليوم) ← يتأكد من وجود تسجيل حضور
  → attendance.checkOutEmployee(time) ← يحسب duration + overtime
  → يحفظ في MongoDB → رد: "تم تسجيل الانصراف بنجاح"
