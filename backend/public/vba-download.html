📊 نظام فلترة الحضور - Excel VBA

ملف Excel تفاعلي مع ماكرو VBA للاتصال المباشر بنظام الحضور

📥 تحميل ملفات الإعداد

تحميل Module1.bas تحميل Module2.bas 📜 تحميل سكريبت PowerShell (تلقائي)

🔧 طريقة الإعداد (يدوي)

  1. فتح Excel ← ملف جديد ← حفظ كـ ملف_ماكرو.xlsm
  2. فتح محرر VBA: Alt + F11
  3. استيراد الوحدات: قائمة File → Import File → اختر Module1.bas و Module2.bas
  4. تفعيل المراجع: Tools → References ← فعّل Microsoft XML, v6.0
  5. إنشاء الأوراق: في Immediate Window (Ctrl+G) اكتب SetupWorksheets واضغط Enter
  6. ضبط الإعدادات: اذهب لورقة "إعدادات" وأدخل رابط الخادم و Token المصادقة
  7. تشغيل الماكرو: ارجع لورقة "واجهة البحث" ← أدخل اسم موظف ← اضغط زر "بحث"

⚡ طريقة الإعداد (تلقائي عبر PowerShell)

  1. حمّل سكريبت Create-ExcelTool.ps1 من الزر أعلاه
  2. شغّله كمسؤول (Run as Administrator)
  3. سينشئ السكريبت ملف نظام_فلترة_الحضور.xlsm على سطح المكتب
  4. افتح الملف في Excel وفعّل المحتوى (Enable Content)
  5. اضبط رابط الخادم و Token في شيت "إعدادات"
  6. استخدم شيت "واجهة البحث" للبحث

⚠️ يتطلب PowerShell سكريبت تشغيل Excel مثبتاً على الجهاز. في حال وجود أخطاء، استخدم الطريقة اليدوية.

🔗 معلومات الاتصال بالخادم

الماكرو يتصل بنفس خادم النظام عبر HTTP. تأكد من أن:
- الخادم شغال (npm start في مجلد backend)
- رابط الخادم في شيت "إعدادات" صحيح (افتراضي: http://127.0.0.1:3000)
- أدخلت رمز JWT Token صحيح في حقل المصادقة
