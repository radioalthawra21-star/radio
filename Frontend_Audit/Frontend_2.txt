1. api.js (الملف الأساسي للـ HTTP)
================================================================================
المسار: frontend\src\services\api.js

الخطأ #1.1
─────────────
الملف: api.js
المسار الكامل: frontend\src\services\api.js
نوع الخطأ: SECURITY - Token Storage
درجة الخطورة: CRITICAL
الوصف: يستخدم localStorage مباشرة للحصول على token: `const token = localStorage.getItem('token')` في كل طلب API
السبب: تخزين JWT في localStorage يجعله عرضة لأي XSS attack
الأثر: أي ثغرة XSS يمكنها سرقة token والوصول الكامل للنظام
الإصلاح المقترح: استخدام HttpOnly Cookies للـ refresh token، وتخزين access token في React state/memory
رقم السطر: ~15-20

الخطأ #1.2
─────────────
الملف: api.js
المسار الكامل: frontend\src\services\api.js
نوع الخطأ: SECURITY - 401 Redirect
درجة الخطورة: MEDIUM
الوصف: في حال 401، يقوم بإعادة التوجيه عبر window.location.href
السبب: استخدام window.location المباشر
الأثر: فقدان حالة التطبيق، عدم تكامل مع React Router
الإصلاح المقترح: استخدام React Router navigate بدلاً من window.location
رقم السطر: ~30-35

الخطأ #1.3
─────────────
الملف: api.js
المسار الكامل: frontend\src\services\api.js
نوع الخطأ: CONFIG - BASE_URL Logic
درجة الخطورة: MEDIUM
الوصف: BASE_URL يساوي '' في PROD ثم يستخدم `BASE_URL ? BASE_URL : '/api'` مما يعني دائماً '/api' في PROD
السبب: منطق غامض قد لا يعمل مع النشر على دومين مختلف عن الـ API
الأثر: فشل طلبات API عند النشر إذا كان API على port/domain مختلف
الإصلاح المقترح: استخدام VITE_API_URL متغير بيئة واضح بدلاً من المنطق المشروط
رقم السطر: ~11-13
