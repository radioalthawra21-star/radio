🔴 أخطاء منطقية خطيرة (Critical)
============================================

1. ManagerEvaluation.hasSubmitted سيمرر دائماً (Bug مؤكد)
   الملف: managerEvaluationController.js:86 + ManagerEvaluation.js:72-75
   التفاصيل:
     - model: hasSubmitted(period, managerId) يبحث عن { period, manager: managerId }
     - controller: hasSubmitted(period, req.user._id) يمرر employee ID كـ managerId
   الأثر: الموظف يُمرر نفسه كـ managerId -> الشرط دائماً false (الموظف ليس مديراً)
          -> النظام يسمح بعدد غير محدود من التقييمات المكررة من نفس الموظف
   الحل: إضافة حقل employeeId إلى EvaluationResponse، وتعديل hasSubmitted
         لاستخدامه

2. AuditLog CSV Export خطأ نحوي (Syntax Error)
   الملف: auditLogController.js:345
   التفاصيل: `const date = new log.createdAt.toLocaleString('ar-SA');`
             JS تفسرها كـ `new (log.createdAt.toLocaleString('ar-SA'))`
             => new Date("string date") -> Invalid Date
   الأثر: تصدير CSV سيعطي تاريخ "Invalid Date" لكل السجلات
